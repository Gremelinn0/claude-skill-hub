# BMAD brainstorming lens

Use this reference when the router detects premature convergence: one idea is being refined before the solution space has been opened, or several options are merely variations of the same idea.

## Purpose

Open the solution space before choosing.

Do **not** run the entire library. Select the smallest useful set of techniques from `bmad-brain-methods.csv`.

## Procedure

1. State the question to explore in one sentence.
2. Inspect the technique library and select 1 to 3 techniques that attack the question from genuinely different angles.
3. Prefer techniques from different categories when the first options are semantically close.
4. Generate several materially different options before evaluating them.
5. Only then return to the router's comparison / decision workflow.
6. Record which techniques materially changed the option space; discard decorative technique use.

## Anti-bias rules

- Do not polish the first plausible answer.
- Do not select three techniques that all produce the same kind of reframing.
- Shift domain when the ideas begin clustering around one perspective.
- Quantity is useful only until the option space becomes meaningfully diverse.
- The router owns convergence; this lens owns divergence.

## Library

`bmad-brain-methods.csv` contains **61 techniques** in the version bundled with this public package.

The list is loaded on demand. Do not dump the whole library into the user-facing answer.
