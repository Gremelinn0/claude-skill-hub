# Deep Reflection Router — public bundle

One installable skill that routes a complex problem through the right reasoning methods instead of making the user choose them manually.

## Included

- problem framing
- structural root-cause analysis
- system optimization
- BMAD brainstorming with a bundled library of 61 techniques
- adversarial pre-mortem

The router uses only the methods the problem needs. It is not a fixed five-step checklist.

## Install

Copy the complete `router-reflexion-profonde` folder into your agent's skills directory.

Keep the `references/` folder with `SKILL.md`: the router depends on those files.

## Use

Invoke `/router-reflexion-profonde` on a non-trivial problem where you want the agent to investigate and choose its reasoning method before execution.
